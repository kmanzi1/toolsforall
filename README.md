# Tools for All

A collection of 10 free, ad free web tools for everyday use hosted on GitHub Pages.

## Tools
- Word & Character Counter
- PX ↔ REM Converter
- JSON Formatter
- Case Converter
- Invoice Generator
- Markdown ↔ HTML Converter
- QR Code Generator
- Password Generator
- Lorem Ipsum Generator
- ROI Calculator

## Vision
Simple, fast, and accessible tools for everyone no ads, no clutter.
